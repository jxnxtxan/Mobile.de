Ausstattungssuche & Preisbewertung

Inoffizielles Open-Source-Projekt eines privaten Entwicklers. Keine Verbindung zu mobile.de; hier gibt es kein Login und es werden keine Daten abgefragt.

Kostenloses Userscript für die Gebrauchtwagensuche auf mobile.de: Es hebt die Ausstattung hervor, die dir wichtig ist, zeigt technische Daten auf einen Blick und bewertet den Preis ausstattungsbereinigt gegenüber ähnlichen Inseraten.

Zum Download auf GitHub Quellcode ansehen

Aktuelle Version · Auf der Release-Seite mobile-ausstattungssuche.user.js anklicken – dein Userscript-Manager zeigt vor der Installation Code und Berechtigungen · Open Source (MIT)

Funktionen

Ausstattung hervorheben

Anhängerkupplung, Standheizung, Head-up-Display, Matrix-LED … – eigene Suchbegriffe mit Farben und Favoriten, direkt auf der Fahrzeugseite.

Ausstattungsbereinigte Preisbewertung

Vergleich mit ähnlichen Fahrzeugen nach Marke, Modell, Kilometerstand, Erstzulassung und Leistung – Ausstattungsunterschiede werden eingerechnet.

Technische Daten kompakt

Ausgewählte Felder wie Leistung, Verbrauch oder Getriebe gebündelt über dem Aktionsbereich.

Auch in der Ergebnisliste

Preis-Einstufung schon in der Suchergebnisliste, optional mit Standard-Sortierung (z. B. Preis aufsteigend).

Merge-Gruppen

Zusammengehörige Treffer werden zu einer Zeile zusammengefasst, z. B. „Außenspiegel elektr. verstellbar, beheizbar, anklappbar“.

Konfiguration mit Backup

Komfortables Popup mit Filter, Drag & Drop, Undo und Import/Export als JSON zum Sichern und Teilen.

Installation in drei Schritten

  1. Userscript-Manager installieren: Tampermonkey oder Violentmonkey.
  2. Auf der Release-Seite bei GitHub die Datei mobile-ausstattungssuche.user.js anklicken und den Dialog bestätigen.
  3. Eine Fahrzeugseite auf suchen.mobile.de öffnen – über Konfiguration im Aktionsbereich alles anpassen.

Updates kommen automatisch. In Chrome muss für Tampermonkey ggf. in den Erweiterungs-Details „Nutzerskripts zulassen“ aktiv sein.

Häufige Fragen

Wie funktioniert die ausstattungsbereinigte Preisbewertung?

Das Skript sammelt ähnliche Inserate aus den Suchergebnisseiten, die du besuchst, und vergleicht den Preis damit. Ausstattung, die dir wichtig ist, wird über Gewichte in den Vergleichspreis eingerechnet. Das Ergebnis reicht von „Sehr guter Preis“ bis „Hoher Preis“; die Schwellen sind einstellbar.

Ist das Skript kostenlos und sicher?

Ja. Der Quellcode ist offen (MIT-Lizenz), das Skript läuft nur auf suchen.mobile.de und speichert seine Daten ausschließlich lokal im Browser. Es sendet keine Daten an Dritte.

In welchen Browsern läuft es?

Überall, wo Tampermonkey oder Violentmonkey läuft: Chrome, Firefox, Edge, Safari, Opera und Brave.

In English

A free, open-source userscript for mobile.de, Germany's largest used-car marketplace. It highlights the equipment you care about on every listing, shows key technical data at a glance and rates the asking price against comparable cars, adjusted for equipment differences. Works with Tampermonkey and Violentmonkey.
